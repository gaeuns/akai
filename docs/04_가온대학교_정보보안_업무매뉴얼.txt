가온대학교 정보보안 업무 매뉴얼 (교직원용)

※ 본 문서는 AKAI 시연을 위해 팀 타닥타닥이 작성한 가상 문서입니다. 실제 기관·인물과 관계가 없습니다.

발행: 정보전산원 정보보안팀 / 버전 3.2 / 2026. 3. 1.


1. 개요

이 매뉴얼은 교직원이 업무 중 지켜야 할 정보보안 수칙과 보안 사고 발생 시 대응 절차를 정리한 것이다. 모든 교직원은 매년 1회 이상 정보보안 교육(온라인 2시간)을 이수하여야 하며, 미이수자는 교내 업무 시스템 접속이 제한될 수 있다.


2. 계정과 비밀번호

2.1 비밀번호 작성 규칙
- 영문 대문자, 영문 소문자, 숫자, 특수문자 중 3종류 이상을 섞어 10자리 이상으로 만든다.
- 생일, 전화번호, 학번·사번처럼 추측하기 쉬운 정보를 쓰지 않는다.
- 직전에 쓴 비밀번호 3개는 다시 쓸 수 없다.

2.2 비밀번호 변경 주기
- 업무 포털 비밀번호는 90일마다 변경한다. 90일이 지나면 로그인 시 변경 화면이 나타난다.
- 개인정보 처리 시스템(학사, 인사, 입학) 비밀번호는 60일마다 변경한다.

2.3 계정 잠금
- 비밀번호를 5회 연속 틀리면 계정이 30분간 잠긴다.
- 잠금을 바로 풀어야 하면 IT 헬프데스크(내선 7000)에 신분 확인 후 요청한다.

2.4 계정 공유 금지
- 계정은 본인만 사용한다. 동료, 조교, 근로 학생에게 계정을 빌려주는 것은 금지한다.
- 업무를 나누어야 하면 해당 시스템 관리자에게 권한 부여를 요청한다.


3. 2단계 인증

다음 시스템은 2단계 인증을 의무로 적용한다.
- 업무 포털 외부 접속(교외에서 접속하는 경우)
- 학사 정보 시스템 성적 입력 화면
- 인사·급여 시스템
- 연구비 관리 시스템

2단계 인증 수단은 교내 인증 앱(가온OTP) 또는 등록된 휴대전화 문자 중 하나를 선택한다. 휴대전화를 바꾸면 정보보안팀 홈페이지에서 인증 수단을 다시 등록한다.


4. PC 보안

4.1 기본 수칙
- 화면 보호기는 10분 이내로 설정하고, 해제 시 비밀번호를 입력하도록 한다.
- 자리를 비울 때는 Windows 키 + L로 화면을 잠근다.
- 백신 프로그램(가온V3)은 항상 실행 상태로 두고, 매주 1회 전체 검사를 한다.
- 운영체제와 업무 프로그램의 보안 업데이트는 공지 후 7일 이내에 적용한다.

4.2 금지 사항
- 불법 소프트웨어 설치
- 개인 클라우드(개인 계정)에 업무 자료 보관
- P2P·토렌트 프로그램 설치
- 업무용 PC로 출처가 불분명한 파일 실행

4.3 PC 반납과 폐기
업무용 PC를 반납하거나 폐기할 때는 정보보안팀에 저장 장치 완전 삭제를 요청한다. 처리 기간은 접수 후 5일(근무일 기준)이다.


5. 개인정보 처리

5.1 개인정보 파일 관리
- 주민등록번호, 계좌번호 등 고유 식별 정보가 들어 있는 파일은 반드시 암호를 걸어 저장한다.
- 개인정보가 담긴 엑셀 파일을 이메일로 보낼 때는 파일 암호를 걸고, 암호는 문자 등 다른 경로로 알려 준다.
- 업무가 끝난 개인정보 파일은 지체 없이 삭제한다. 보관 기간이 정해진 자료는 기록관리 규정을 따른다.

5.2 출력물 관리
- 개인정보가 담긴 출력물은 출력 즉시 회수한다.
- 폐기할 때는 문서 세단기를 사용한다. 일반 폐지함에 버리는 것은 금지한다.

5.3 개인정보 점검
각 부서는 매년 6월과 12월에 부서 PC의 개인정보 파일을 점검 프로그램(가온스캔)으로 검사하고 결과를 정보보안팀에 제출한다.


6. 이메일과 피싱

- 발신자가 확실하지 않은 메일의 첨부 파일과 링크는 열지 않는다.
- "계정이 정지됩니다", "비밀번호를 확인하세요" 같은 메일로 로그인 화면이 나타나면 주소창의 주소가 gaon.ac.kr로 끝나는지 확인한다.
- 의심 메일은 열지 말고 정보보안팀 신고 주소(security@gaon.ac.kr, 가상 주소)로 전달한 뒤 삭제한다.
- 정보보안팀은 이메일로 비밀번호를 묻지 않는다.


7. 이동식 저장 매체

- 업무용 USB는 부서별로 등록한 보안 USB만 사용한다. 등록 신청은 정보보안팀 홈페이지에서 한다.
- 보안 USB를 잃어버리면 24시간 이내에 정보보안팀에 신고한다.
- 개인 USB로 업무 자료를 옮기는 것은 금지한다.


8. 보안 사고 대응 절차

보안 사고(악성코드 감염, 계정 도용 의심, 개인정보 유출 등)가 의심되면 다음 순서로 대응한다.

  1단계: 즉시 네트워크 연결을 끊는다(랜선 분리, 와이파이 끄기). PC 전원은 끄지 않는다.
  2단계: IT 헬프데스크(내선 7000) 또는 정보보안팀(내선 7100)에 바로 신고한다.
  3단계: 정보보안팀의 안내에 따라 증거를 보존한다. 임의로 파일을 지우거나 프로그램을 설치하지 않는다.
  4단계: 정보보안팀이 조사하고 복구한다. 개인정보 유출이 확인되면 72시간 이내에 정보주체에게 통지하고 관계 기관에 신고한다.
  5단계: 사고 보고서를 작성하고 재발 방지 대책을 부서에 공유한다.

신고 가능 시간: 평일 09:00~18:00 (그 외 시간은 당직실 내선 1119)


9. 위반 시 조치

정보보안 수칙을 위반한 경우 위반 정도에 따라 다음과 같이 조치한다.
- 1회 위반(경미): 주의 통보, 보안 교육 추가 이수(1시간)
- 2회 위반 또는 중대한 위반: 시스템 접근 권한 일시 정지, 소속 부서장 통보
- 고의 또는 중과실로 개인정보 유출: 징계 의결 요구, 관계 법령에 따른 조치


10. 문의처

- IT 헬프데스크: 내선 7000 (계정, PC 장애)
- 정보보안팀: 내선 7100 (보안 사고, 보안 USB, 교육)
- 개인정보보호 담당: 내선 7150 (개인정보 처리, 점검)
