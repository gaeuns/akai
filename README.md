# AKAI — 문서 요약·Q&A 지식베이스

> **A**rchive + **AI**. 기관 문서를 올리면 AI가 요약하고, 문서 내용을 근거로만 질문에 답하는 웹 지식베이스

융합SW모델설계 PBL (2026학년도 2학기) · 과제 10 · 팀 **타닥타닥**

## 주요 기능 (MVP)

| ID | 기능 | 설명 |
| --- | --- | --- |
| F-01 | 문서 업로드·추출·분할 | PDF·TXT 업로드 → 텍스트 추출 → 페이지·문단 단위 조각(Chunk) 저장 |
| F-02 | AI 요약·키워드 | 문서별 요약(5문장 이내)과 핵심 키워드 5개 생성, "AI 생성" 표시, 관리자 수정 가능 |
| F-03 | 근거 기반 Q&A | 관련 조각만 근거로 답변, 근거 문서명·페이지·원문 표시, 근거 없으면 "문서에서 찾을 수 없음" |
| F-04 | 분류·태그·검색 | 분류·태그 관리, 제목·태그·키워드 검색 |
| F-05 | 질의 이력 | 질문·답변·근거·일시 저장 및 조회 |
| F-08 | 로그인·역할 구분 | 미리 등록된 계정으로 로그인, 이용자·관리자 권한 구분 |

확장(선택): F-06 임베딩 기반 의미 검색, F-07 여러 문서 비교 요약

| 영역 | 기술 |
| --- | --- |

## 협업 규칙

- `main` 브랜치에 직접 푸시하지 않는다. 기능 브랜치에서 작업한 뒤 PR을 올린다.
- 모든 PR은 다른 팀원 1명이 리뷰한 뒤 병합한다.
- 브랜치 이름: `feat/F-01-upload`, `fix/qa-empty-answer`, `docs/week11-design`, `test/F-03` 등
- 커밋 메시지: `[F-01] PDF 텍스트 추출 구현`처럼 기능 ID를 앞에 붙인다.
- AI를 활용한 작업은 `docs/ai-log/`에 AI 활용 로그로 남긴다.
